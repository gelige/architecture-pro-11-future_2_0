# Агрегаты

Ключи - UUID; `aggregateVersion` защищает от одновременных изменений. Доступ ограничен организацией и регионом.

| BC  | Агрегат / ключ; что входит                                             | Обязательные правила                                                                                                | События  |
|-----|------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------|----------|
| PAT | Пациент / `patientId`; профиль и согласия                              | Повтор регистрации с тем же внешним ключом не создаёт пациента; клинических данных нет                              | E01      |
| PAT | Визит / `visitId`; запись, статус, ссылка для расчётов                 | Завершить можно только начатый визит и один раз; нужны расчётный аккаунт и версия тарифа                            | E02      |
| CLN | Медкарта / `medicalRecordId`; записи и подтверждения врача             | Одна активная карта на локальный `patientId`; подпись уполномоченного врача; исправления сохраняют историю          | —        |
| CLN | Исследование / `studyId`; назначение и ссылка на результат             | Назначение относится к существующей карте; принимается результат своей версии задания; заключение ИИ проверяет врач | E03      |
| AI  | Задание анализа / `analysisJobId`; статус, модель, ссылка на результат | Одно задание на версию назначения; итог — либо сохранённый результат, либо отказ                                    | E04, E05 |
| BIL | Счёт / `invoiceId`; позиции, итог, зачтённые платежи                   | Итог положителен и равен сумме позиций; один счёт на визит; платёж зачитывается один раз; валюты совпадают          | E06, E10 |
| CRD | Кредитная заявка / `applicationId`; согласие, KYC, решение             | Решение после обязательных проверок; ссылка на неизменную версию счёта                                              | —        |
| CRD | Кредитный договор / `contractId`; условия и статус выдачи              | Только по одобренной заявке и подписям сторон; один договор на заявку; «создан» не значит «выдан»                   | E07      |
| PAY | Платёж / `paymentId`; сумма, назначение, статус, подтверждение         | Сумма положительна; проведение подтверждает банковское ядро; повтор с тем же `idempotencyKey` не создаёт перевод    | E08, E09 |
| OPS | Заказ снабжения / `supplyOrderId`; позиции, принятые отгрузки          | Количества положительны; приёмка не превышает заказ; отгрузка принимается однократно                                | E11      |
| OPS | Складская позиция / `stockId`; препарат, партия, место, остаток        | Остаток не ниже нуля; позиция отгрузки приходуется один раз                                                         | —        |
| OPS | Назначение сотрудника / `assignmentId`; сотрудник, роль, срок          | Начало раньше окончания; назначение утверждает ответственный руководитель                                           | —        |
| PHR | Заказ поставки / `pharmaOrderId`; позиции, резервы, отгрузки           | Один заказ на `supplyOrderId`; отгрузка не превышает резерв; просроченные партии запрещены                          | E12      |
| PHR | Партия / `batchId`; срок годности, остаток, резервы                    | Нельзя зарезервировать больше остатка; резерв сохраняется одной транзакцией                                         | —        |
| EQP | Прибор / `deviceId`; допуск и обслуживание                             | Серийный номер уникален у производителя; неисправный прибор недоступен; возврат требует подтверждения обслуживания  | E13      |
| ANA | Определение отчёта / `reportId`; показатели, фильтры, версия           | Только разрешённые наборы; доступ проверяется при каждом выполнении                                                 | —        |

В таблице указаны только [ключевые междоменные события](events.md), без внутренних событий резервирования и кадрового
учёта.
